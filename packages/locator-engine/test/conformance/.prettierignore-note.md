# Why the golden is Prettier-formatted

`playwright-golden.json` is generated by `refresh-golden.mjs` and then committed.
`pnpm format:check` covers it like any other file, so the generator writes
2-space-indented JSON with a trailing newline — the shape Prettier produces.

If a future change to the generator makes `format:check` fail, fix the
generator's output rather than adding the file to `.prettierignore`: an
unformatted generated file is a diff full of noise the next time it is
regenerated.
