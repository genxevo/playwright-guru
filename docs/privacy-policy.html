Privacy Policy — Playwright Guru

Last updated: 18 August 2026

Applies to: Playwright Guru Chrome Extension, version 0.1.0 (Developer Preview)

Summary

Playwright Guru does not collect, transmit, sell, or share any data. Everything the extension does happens locally in your browser. It makes no network requests of any kind.

What the extension accesses

When you explicitly activate the element picker — by opening the Playwright Guru side panel and clicking an element on the page, or by selecting an element in the DevTools Elements panel — the extension reads structural information about that element from the page you are viewing. This includes the element's tag name, attributes (such as id, class, role, aria-label, placeholder, alt, title, and test-id attributes), its visible text, and its position relative to surrounding elements.

This information is used for one purpose only: to compute Playwright, CSS, and XPath locators for the element you selected and display them to you.

The extension does not read page content at any other time. It does not monitor your browsing, and it does not run in the background collecting information.

Recording mode

The side panel includes a recording control. When you start a recording, the extension captures the actions you perform on the page — such as clicks, text entered into form fields, dropdown selections, and page navigations — so it can generate a Playwright test script from them. Each recorded action stores the element's identifying attributes, the value you entered where one applies, the page URL for navigations, and a timestamp.

Recording only happens while you have explicitly started it, and stops when you stop it. Like everything else in this extension, recorded actions are held in local extension storage on your own computer and are never transmitted anywhere.

Please note: because a recording captures the values you type, avoid recording while entering real passwords, personal data, or other sensitive information. Use test credentials instead. You can clear a recording at any time from the side panel.

What is stored, and where

The extension stores the following using Chrome's local extension storage (chrome.storage.local), which resides on your own computer:

  • the generated code you have added to the code buffer
  • your selected output language (TypeScript, JavaScript, Python, Java, or C#)
  • the most recent element you picked
  • whether the picker is currently active
  • whether a recording is currently in progress
  • the actions captured during a recording, as described above

This data never leaves your device. The extension does not use Chrome's sync storage, so none of it is uploaded to Google or synchronised across your devices. You can erase all of it at any time using the Clear controls in the extension, or by removing the extension from Chrome.

What the extension does NOT do

  • It makes no network requests. It contains no code that calls fetch, XMLHttpRequest, WebSocket, or sendBeacon.
  • It sends no page content, code, or usage data to any server, including our own.
  • It contains no analytics, telemetry, or tracking of any kind.
  • It loads no remote code. All code is contained in the published package.
  • It uses no third-party services.
  • It does not access your cookies, browsing history, bookmarks, downloads, or account identity.
  • It does not read your clipboard. When you press a copy button, it writes the generated code to your clipboard; it never reads clipboard contents.
  • It collects no personally identifiable information, authentication credentials, financial information, health information, or location data.

Permissions, and why each is needed

Permission Why it is required
activeTab To access the tab you are actively inspecting when you use the picker.
scripting To inject the element-picker script into that tab so a clicked element can be analysed.
storage To save your code buffer, language preference, picker state, and recordings locally.
sidePanel The extension's user interface is a Chrome side panel.
Host access to all sites (<all_urls>) Test automation engineers generate locators on arbitrary applications, which cannot be listed in advance. It is also required so the picker works on tabs that were already open before the extension was installed. Page content is read only when you explicitly activate the picker or a recording, and is never transmitted.

Data sharing

We do not sell, transfer, or share your data with anyone, because we never receive it. No data is transmitted off your device.

Children's privacy

Playwright Guru is a developer tool intended for professional software engineers. It is not directed at children and collects no data from anyone.

Changes to this policy

If the extension's data behaviour changes in a future version, this policy will be updated before that version is published, and the "Last updated" date will change.
